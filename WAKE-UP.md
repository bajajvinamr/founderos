## Operational lessons surfaced this session

1. **Planning files MUST be committed**, not held as untracked working-tree state. Worktree HEAD moves sweep untracked files. (Recovery: PR #197/#203/#205 all faced this; mitigation: tracker files were re-persisted via commit `ea56be2`.)

2. **`Agent({isolation: "worktree"})` is not 100% partitioned** — worktree branch state is correctly isolated, but CWD can be dragged into a worktree subdirectory and modifications to existing tracked files can leak into the parent checkout's git status. Defense: always use absolute paths for file operations; always `cd /Users/vinamr/Projects/founderos &&` prefix for git commands; always `git diff --name-only HEAD` before staging.

3. **Agents may self-rename worktree branches** — about half the agents this loop self-renamed to `worktree-agent-<id>` even when the prompt specified a branch name. Branch name in agent prompts is descriptive intent, not contract. Always resolve via `git worktree list` before referencing.

4. **Subagent harness cannot persist arbitrary planning files** — Wave 1.5 synthesizer agent could not write its README.md + BACKLOG.md to disk; orchestrator had to persist inline. The 81-ticket BACKLOG.md content lives only in compacted orchestrator memory. Future loops should commit the BACKLOG.md from orchestrator immediately after the synthesizer returns, not rely on the synthesizer's write.

5. **Bundle-savings estimates from ticket research are unreliable** — L2-E01 measured -17.7KB entry vs. predicted 459KB. Rollup chunk-hoisting makes the actual graph different from the import-source visible at the file level. Validate with measured `gzip -c | wc -c` before claiming a perf win.

6. **Shadow Council hook fires on planning-file keywords** — `STATE.md` and `WAKE-UP.md` mentioning the words `auth/payment/migration/security` triggers `🌑 /council before implementing` on every Write. Recommend hook-level fix: switch from content-grep to path-and-diff-shape signals (e.g., only flag writes to `server/src/auth/`, `server/src/middleware/billing-gate.ts`, `packages/db/src/migrations/`).

7. **"Honest reporting of partial-wrong premises" scales the loop better than orchestrator-side planning** — L2-E01's "ticket premise was partially wrong", L2-D16's "Drizzle v7 has no hash field", L2-D17's "no instance_id columns exist" were each more valuable than the originally-scoped task. Each surfaced architectural truth that informed the next phase's dispatch.
