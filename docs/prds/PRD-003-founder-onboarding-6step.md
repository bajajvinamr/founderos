# PRD-003: Founder-native Onboarding (6-step)

**Status:** Shipped
**Owner:** @vinamr
**Last updated:** 2026-04-21
**Related:** Wave 15A, `ui/src/components/onboarding`, Onboarding routes

## Problem

Signup → generic Paperclip wizard → boring agent setup. Every founder answers the same 3 questions (vision, bottleneck, team size), gets the same 4 agents, and spends 15+ minutes wading through checkboxes before seeing anything real. No founder-specific customization means agents start with generic charters and no context. Time to first decision-approved is 2+ hours because the founder has to manually edit agent descriptions, define their actual bottleneck, and wait for agents to re-read and understand.

## Goal

A 6-step flow optimized for founders (vision + bottleneck → auto-generated agent charters → first decision in < 10 min) replaces the generic Paperclip onboarding, with zero copy-paste required.

## Non-goals

- Multiple onboarding flows (one opinionated path only)
- A/B testing different onboarding sequences
- Onboarding completion analytics (future PR)
- Cofounder workflow (out of scope; manual invite + setup)
- Mobile-optimized onboarding (desktop-first for launch)
- Pre-built templates for specific industries (vision input replaces this)

## User stories

1. As a founder I want to input my vision in 1 paragraph so that agents understand my market + goals from day one.
2. As a founder I want to pick 1-2 bottlenecks (e.g., "hiring", "content") so that agents' first-decision recommendations are tailored, not generic.
3. As a founder I want to see AI-generated agent charters customized to my company so that I'm not creating agents from scratch.
4. As a founder I want to edit those charters inline before confirming so that I can add my own flavor and constraints.
5. As a founder I want my first decision (e.g., "Hire FX specialist") to appear in the Decision Inbox immediately post-signup so that I can approve it within 10 minutes.
6. As an operator I want the entire signup → agents → first decision to be one atomic transaction so that a failed step doesn't leave orphan rows.

## Success metrics

- **Onboarding completion rate:** ≥ 85% of signups complete all 6 steps
- **Time-to-first-decision:** Median time from signup completion to first decision-approved ≤ 10 min
- **Charter satisfaction:** ≥ 80% of founders approve generated charters without edit
- **Decision approval rate:** ≥ 70% of first decisions are approved (signal that recommendations are contextual)
- **Dropout rate:** < 5% dropout before step 3 (vision input)

## UX / Flow

### Step 1: Vision
- **Input:** 1-2 paragraph free-text describing company + market
- **Validation:** Min 10 words, max 4000 chars
- **Next:** → Step 2

### Step 2: Team size + Bottleneck
- **Input A:** Radio select: "Solo founder" / "Cofounder" / "Small team (3-5)"
- **Input B:** Checkbox multi-select: pick 2 bottlenecks from [Hiring, Content, Growth, Fundraising, Product, Finance, Operations]
- **Validation:** Team size required, ≥ 1 bottleneck selected
- **Next:** → Step 3 (if solo) OR prompt cofounder email (if cofounder)

### Step 3: Meet your agents
- **Display:** 4 agent cards auto-generated by Claude (CoS, CMO, Content, Finance)
- **Card shows:** Name, title, avatar (auto-picked emoji), charter (100 words)
- **Action:** "Edit charter" inline (expands textarea), "Next"
- **Validation:** Charters must be valid on save
- **Next:** → Step 4

### Step 4: Connect integrations
- **Display:** Slack + HubSpot + Notion checkboxes
- **Action:** Check boxes you want agents to access; uncheck to skip
- **Validation:** Optional (all can be skipped)
- **Next:** → Step 5

### Step 5: API key setup
- **Input:** Paste Anthropic API key
- **Validation:** Key format: `sk-ant-*`, required (can't skip)
- **Next:** → Step 6

### Step 6: Confirm + finalize
- **Display:** Summary: vision (truncated), bottlenecks, agents (names only), integrations (checkmarks)
- **Action:** "Launch" button → atomic transaction
- **On success:** Redirect to `/decisions` → first 3 decisions already in Inbox
- **On failure:** Error message + "Try again" (doesn't lose form state)

## API / Data contract

### Tables touched

- **companies** (create)
- **agents** (create 4 rows)
- **company_members** (create for founder)
- **secrets** (create for Anthropic key)
- **approvals** (create 3 rows for first decisions)
- **integration_configs** (create if Slack/HubSpot/Notion checked)

### Endpoints

| Method | Path | Body | Response |
|--------|------|------|----------|
| POST | `/api/onboarding/bootstrap` | Bootstrap payload | `{companyId, agentIds, secretKey}` (201) |
| POST | `/api/onboarding/first-decisions` | `{companyId, bottlenecks, vision}` | List[FirstDecision] |
| POST | `/api/onboarding/accept-decision` | `{decisionId, companyId}` | `{approvalId}` (201) |

### Bootstrap payload schema

```typescript
{
  vision: string,                          // 1-2 paragraphs
  bottlenecks: string[],                   // e.g., ["hiring", "content"]
  team: "solo" | "cofounder" | "small_team",
  cofounder?: { name: string, email: string },
  anthropicKey: string,                    // sk-ant-*
  integrations: {
    slack?: boolean,
    hubspot?: boolean,
    notion?: boolean
  },
  charters: {
    cos: { name, title, avatar, charter, firstPriority },
    growth: {...},
    content: {...},
    finance: {...}
  },
  companyName?: string                     // defaults to "My Company"
}
```

### First decision structure

```typescript
{
  id: string,           // temp ID (doesn't persist yet)
  title: string,        // e.g., "Hire FX specialist"
  type: string,         // "hire_agent" | "create_content" | etc
  description: string,  // Why this decision matters
  bottleneck: string,   // Which bottleneck it addresses
  payload: object       // Decision-type-specific data
}
```

### Events

- `onboarding.started` → Operator dashboard shows new funnel entry
- `onboarding.completed` → Company + agents live, first decisions in Inbox
- `onboarding.failed` (step N) → Error logged to Sentry + rolled back

## Risks & open questions

- **Cold-start latency:** Generating agent charters + first decisions on the fly may take 2-3 sec (Claude API call). Acceptable? OR pre-generate server-side in background + show spinner?
- **Anthropic key validation:** We accept the key but don't test it until agent runs. If key is wrong/revoked, founder discovers mid-week. Mitigated by test call post-bootstrap (TBD).
- **Vision input quality:** If founder pastes 10 words of gibberish, Claude charters will be garbage. Mitigated by min 10-word requirement + founder edits charters in step 3.
- **Integration OAuth scope creep:** If we connect Slack but founder hasn't created a channel yet, agent can't post. Mitigated by "optional integrations" + agent error handling.
- **Cofounder invite flow:** If founder enters cofounder email in step 2, do we auto-invite or wait? Currently: auto-invite + cofounder joins on their own signup. May need follow-up UX.
- **Rollback on failure:** Transaction wraps the whole flow; if agent creation fails, all prior steps roll back. Verify with test.

## Out of scope (but considered)

- Industry-specific wizard flows (vision + bottleneck replaces this)
- Team member import from email lists
- Slack workspace scan to auto-connect
- Calendar scan to auto-populate "founder available hours"
- Multi-language onboarding (English only for MVP)
- Onboarding email drip (future PR)
